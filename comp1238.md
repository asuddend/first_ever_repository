## Week 1 - History
- Early writing systems like cuneiform were used to record information such as trade and numbers
- Printing inventions like Gutenberg’s press made books cheaper and spread knowledge
- Modern text tools, fonts, and keyboards evolved from historical writing and printing systems
## Week 2 - Bits and Bytes
- Computers use binary bits and bytes to represent numbers and text in memory
- RAM is volatile memory while SSD and HDD store data permanently
- ASCII maps numbers to characters so computers can display text
## Week 3 - Text Structure
- Markdown and HTML use markup and indentation to structure and format text
- Special characters need escaping so they display correctly in text
- Unicode and UTF 8 allow computers to represent many more characters than ASCII
## Week 4 - Keyboards and Editors
- Text editors like VS Code and Vim are used to write and edit code efficiently
- Keyboard mastery and shortcuts help increase speed and productivity
- Search tools like Ctrl F help find text quickly
- ## Week 5 - CLI
- Command line allows users to control computers using text commands
- Commands like ls, cd, and mkdir help navigate and manage files
- SSH and tools like grep and tmux allow remote access and advanced control
